Download Curl

Curl is a drop-in replacement for the curl command-line tool, written in C# on .NET 10. Every file is in the rolling preview pre-release. The table below is resources.json (version 0.2.0-rolling.194, commit 178e22417171394198f1764d6acc1275f5cc893c); verify a download against its SHA-256 or with SHA256SUMS.

Which .NET library

Curl.Api is for new .NET work: an async, HttpClient-shaped client. Libcurl is for porting C or libcurl code to .NET: the libcurl API one call for one call.
