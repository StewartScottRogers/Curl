Download Curl

Curl is a drop-in replacement for the curl command-line tool, written in C# on .NET 10. Every file is in the rolling preview pre-release. The table below is resources.json (version 0.2.0-rolling.241, commit 29cb28dc2c24494971eee59fb5a2394f2160620b); verify a download against its SHA-256 or with SHA256SUMS.

Which .NET library

Curl.Api is for new .NET work: an async, HttpClient-shaped client. Libcurl is for porting C or libcurl code to .NET: the libcurl API one call for one call.
