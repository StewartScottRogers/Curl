Download Curl

Curl is a drop-in replacement for the curl command-line tool, written in C# on .NET 10. Every file is in the rolling preview pre-release. The table below is resources.json (version 0.2.0-rolling.333, commit 153bf2e0dee4b4d3f1a18f29757d07a1e3d02cff); verify a download against its SHA-256 or with SHA256SUMS.

Which .NET library

Curl.Api is for new .NET work: an async, HttpClient-shaped client. Libcurl is for porting C or libcurl code to .NET: the libcurl API one call for one call.
