# Doing

Tasks claimed by an active `/task-run`. A task is moved here before its first edit
and never stays here once the run ends — it goes to `Done`, `Blocked`, `Deferred`, or
back to `Backlog`. Anything left here outside an active run was abandoned mid-run.

This file is not a task; it keeps the folder in Git when nothing is in progress. See
`../README.md`.
