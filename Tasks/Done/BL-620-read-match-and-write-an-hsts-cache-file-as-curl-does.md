# BL-620 — Read, match and write an HSTS cache file as curl does

## Goal

An `HstsCache` in `Curl.Core.UnitLibrary` reads curl 8.21.0's HSTS file format (`[.]host "YYYYMMDD HH:MM:SS"` lines, `unlimited`, comments), answers whether a host (or a parent with `includeSubDomains`) is known and unexpired at a given time, applies a `Strict-Transport-Security` header value (`max-age`, `includeSubDomains`, `max-age=0` removal), and writes the file back in curl's format and order.

## Context

- Conformance audit 2026-09-28, row 20 (Major, M). Wiring is BL-621.
- Format: https://curl.se/docs/hsts.html (8.21.0 reference) and `CurlManual.txt` (`--hsts`). Take text in and give text out; inject `TimeProvider`.
- Measure the written file: run the reference curl with `--hsts cache.txt` against `Record-CurlExchange.ps1 -Tls -k` answering `Strict-Transport-Security: max-age=31536000; includeSubDomains`, and with `max-age=0`, and copy the file.

## Acceptance criteria

- [x] Measured first as above; the written files copied into Notes.
- [x] `Curl.Core.UnitTests` pin reading, matching (exact, subdomain, expired), header application and the written text byte for byte for the measured cases.
- [x] `dotnet build Curl.slnx -warnaserror` is clean, the fast tests pass, and `Measure-CodeQuality.ps1 -Library Curl.Core.UnitLibrary` reports 100% line and branch coverage and no failing member.

  `LatestWritableExpiryOffWindows` (year 2147485547, from glibc, not measured).

### Measurements (curl 8.21.0 mingw Schannel, 2026-09-29 UTC)

Every run: `Record-CurlExchange.ps1 -Tls -Port 18443 -Response 'HTTP/1.1 200 OK\r\nStrict-Transport-Security: <value>\r\nContent-Length: 0\r\n\r\n' -CurlArgs '-sk,--hsts,<file>,<url>'`, URL `https://localhost:18443/` unless stated. Files as written, CR LF shown as `\r\n`; `H` stands for the two header lines
`# Your HSTS cache. https://curl.se/docs/hsts.html\r\n# This file was generated by libcurl! Edit at your own risk.\r\n`.

- No file, `max-age=31536000; includeSubDomains` at 05:59:02 ->
  `H.localhost "20270929 05:59:02"\r\n`
- That file, `max-age=0` -> `H`
- Seeded (LF) file below, `max-age=60` at 06:00:01:
  ```
  # c
     # indented

  plain.test "unlimited"
  .sub.test "20300101 00:00:00"
  old.test "20200101 00:00:00"
  bad.test 20300101
  dup.test "20300101 00:00:00"
  dup.test "20310101 00:00:00"
  DUP.test "20290101 00:00:00"
  trail.test. "20300101 00:00:00"
  garbage.test "not a date"
    lead.test "20300101 00:00:00"
  two.test  "20300101 00:00:00"
  tab.test<TAB>"20300101 00:00:00"
  x.test "20300101 00:00:00" y
  cr.test "20300101 00:00:00"<CR>
  localhost "20300101 00:00:00"
  last.test "20300101 00:00:00"      (no final LF)
  ```
  -> `Hplain.test "unlimited"\r\n.sub.test "20300101 00:00:00"\r\ndup.test "20310101 00:00:00"\r\ntrail.test "20300101 00:00:00"\r\nlead.test "20300101 00:00:00"\r\ncr.test "20300101 00:00:00"\r\nlocalhost "20260929 06:01:01"\r\nlast.test "20300101 00:00:00"\r\n`
- `a.test "20300101 00:00:00"`, `max-age=99999999999999999999999; includeSubDomains` ->
  `Ha.test "20300101 00:00:00"\r\n.localhost "unlimited"\r\n`; `max-age=9223372036854775807` -> `...localhost "unlimited"\r\n`
- `.localhost "unlimited"`, URL `http://www.localhost:18443/`, `-v`: `* Switched from HTTP to HTTPS due to HSTS => https://www.localhost:18443/`, `max-age=60` at 06:00:27 -> `H.localhost "unlimited"\r\nwww.localhost "20260929 06:01:27"\r\n`
- `localhost "unlimited"` (no dot), `http://www.localhost:18443/` -> no switch (exit 56 on the TLS server), file `Hlocalhost "unlimited"\r\n`
- `.localhost "unlimited"`, `http://LOCALHOST.:18443/` -> switched; `max-age=60` at 06:00:29 -> `Hlocalhost "20260929 06:01:29"\r\n` (updated in place, flag cleared)
- `localhost "20200101 00:00:00"`, `http://localhost:18443/` -> no switch, file `H`
- `.sub.test`, `.a.sub.test`, `b.sub.test` (all 2030), `max-age=0` -> `H.sub.test "20300101 00:00:00"\r\nb.sub.test "20300101 00:00:00"\r\n`
- `https://127.0.0.1:18443/` and `https://0x7f.1:18443/` with `max-age=60` -> `H` (IP hosts learn nothing)
- Header values, each on an empty file (`localhost` line written, or `H` only):
  `max-age="60"` -> `localhost`; `max-age = "60" ; includesubdomains`, `MAX-AGE=60;INCLUDESUBDOMAINS`, `max-age=60x; includeSubDomains`, `includeSubDomainsX; max-age=60`, `  max-age=60  ;  ;includeSubDomains  ` -> `.localhost`; `foo=bar; max-age=60`, `max-age=60, includeSubDomains` -> `localhost`; `max-age=60; max-age=70`, `includeSubDomains`, `max-age=`, `max-age="60`, `max-age=60; includeSubDomains; includeSubDomains`, `max-age=-5`, `max-age=+5` -> `H` only.
- Write limit: `max-age` to 3000-12-31 23:59:57 and 3001-01-01 00:00:04, 07:59:57, 08:00:04 all written; to 9999-12-31 23:59:56 and 10000-01-01 00:00:04, and `max-age=300000000000`, leave the old file untouched (LF, no comments). Seeded single lines: `e "30010101 20:59:59"` written, `e "30010101 21:00:00"` (and later, up to `99991231 23:59:59`) leaves the file untouched.
- Seeded dates: `20300230` -> `"20300302 00:00:00"`; `20300101 23:59:60` -> `"20300102 00:00:00"`; `20300101 00:00` and `20300101 0:0:0` -> `"20300101 00:00:00"`; `20300101` -> `"20300101 00:00:00"`; dropped: `UNLIMITED`, `20301301`, `20300101 24:00:00`, `2030-01-01`, `Tue, 01 Jan 2030 00:00:00 GMT` (18+ chars), `20300101 00:00:00Z`, `20300101 T00:00:00`, `20300101  00:00:00`, `2030010 00:00:00`, `19691231 23:59:59`.
