# BL-622 — Read, match and write an alt-svc cache file as curl does

## Goal

An `AltSvcCache` in `Curl.Core.UnitLibrary` reads curl 8.21.0's alt-svc file format (one line per entry: source ALPN, host, port, destination ALPN, host, port, expiry, persist and priority fields), parses `Alt-Svc` header values (RFC 7838: `h1`/`h2`/`h3` alternatives, `ma`, `persist`, `clear`), answers the alternative for an origin at a given time, and writes the file back in curl's format.

## Context

- Conformance audit 2026-09-28, row 20 (Major, M). Wiring is BL-623.
- Format: https://curl.se/docs/alt-svc.html (8.21.0 reference) and `CurlManual.txt` (`--alt-svc`). Take text in, give text out; inject `TimeProvider`.
- Measure the written file: the reference curl with `--alt-svc cache.txt` against `Record-CurlExchange.ps1 -Tls -k` answering `Alt-Svc: h2=":8443"; ma=60, h3=":443"` and `Alt-Svc: clear`; copy the file.

### Measurements (curl 8.21.0 mingw Schannel, 2026-09-29 05:20-05:42 UTC)

Command, run from a scratch folder, with `-Response` varied:

```
powershell -NoProfile -ExecutionPolicy Bypass -File Record-CurlExchange.ps1 -Port 18443 -Tls -OutDirectory out `
  -Response 'HTTP/1.1 200 OK\r\nAlt-Svc: h2=\":8443\"; ma=60, h3=\":443\"\r\nContent-Length: 0\r\n\r\n' `
  -CurlArgs '-k','--alt-svc','cache.txt','https://localhost:18443/'
```

`Alt-Svc: h2=":8443"; ma=60, h3=":443"` wrote (every line ends CR LF):

```
# Your alt-svc cache. https://curl.se/docs/alt-svc.html
# This file was generated by libcurl! Edit at your own risk.
h1 localhost 18443 h2 localhost 8443 "20260929 05:21:05" 0 0
h1 localhost 18443 h3 localhost 443 "20260930 05:20:05" 0 0
```

Then `Alt-Svc: clear` against that file wrote only the two comment lines.

Further cases (file lines after the comments; each file started empty unless seeded):

- `h3="alt.example:8443"; ma=120; persist=1, h2=":9443", foo=":1"` ->
  `h1 localhost 18443 h3 alt.example 8443 "20260929 05:23:23" 1 0`,
  `h1 localhost 18443 h2 localhost 9443 "20260930 05:21:23" 0 0` (ma per alternative; unknown ALPN skipped).
- `h2="[::1]:8443"` -> `h1 localhost 18443 h2 [::1] 8443 "20260930 05:21:44" 0 0`.
- Two headers `h2="[::1]:8443"; ma="30"` then `h3="b.example:1"` -> only `h1 localhost 18443 h3 b.example 1 "20260930 05:21:24" 0 0`.
- `H2=":8443"` -> nothing (ALPN case-sensitive). `h2=":8443" ; MA = 5` -> ma 5.
- `h2=":8443";MA=5;PERSIST=1, h3=":1"; persist=2` -> persist 1 then 0.
- `h2=":1";ma=abc, h3=":2";ma=0, h2=":3"; ma=99999999999999999999` -> +24 h, +0, +24 h.
- `h2="a.example:99999", h3=":4"` -> nothing ("Unknown alt-svc port number, ignoring.").
- `h3=":5", h2="a.example"` -> only the h3 entry. `h2=":8443"; foo, h3=":443"` -> only h2.
- `h2=":8443"; ma=999999999999999` -> no file written at all (Windows gmtime limit; ADR deviation).
- Hosts: 2048 characters read, 2049 "Bad alt-svc hostname, ignoring."; bracketed 46 read, 47
  "Bad alt-svc IPv6 hostname"; in the file a 2049-character source or destination host drops the line.
- `clear` with seeded entries for `h1 other.example 443`, `h2 localhost 18443`, `h1 localhost 18444`,
  `h1 localhost 18443` kept the first three.
- Seeded file (no Alt-Svc) kept only: `h1 localhost 18443 h1 localhost 18443 ...`, `h1 [::1] 443 h2 [::1] 443`
  (from unbracketed `::1`), `h1 [::2] 443 h2 [::3] 443`, `h1 f.example 443 h2 b.example. 443` (from
  `f.example.`), and a last line with no LF; dropped: an expired 2020 entry, `"garbage"` date,
  `persist` 5, priority 7, trailing ` extra`, unquoted date, double space, `H1`, `h9`, port 65536,
  an RFC 1123 date, a trailing space. Leading spaces/tab and CR LF lines were read.
- File line limit: a 4093-character line read, 4094 (even a comment) stops reading the file.
