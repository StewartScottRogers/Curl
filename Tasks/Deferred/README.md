# Deferred

Tasks deliberately set aside. Nothing stops them; they are just not wanted now. The
latest `Log` entry in each file says why, and when to look again. A deferred task
returns to `Backlog` when someone decides it is wanted.

Abandoned work comes here with its reason rather than being deleted, so its ID and
history survive.

This file is not a task; it keeps the folder in Git when nothing is deferred. See
`../README.md`.
