# CurlSurface: transfer options for the broker schemes stomp and stomps

curl's generic transfer options (`-v`, `-o`, `-O`, `-w`, `--fail`, `--fail-with-body`, `-m`) for `stomp` (port 61613,
in clear) and `stomps` (port 61614, over TLS with `-k`), run through the real curl command line in process against a
`ScriptedReferenceServer` (`Curl.Conformance.Extended.UnitTests/CurlSurface/Transfer/Brokers/Stomp/`, one case file per
scheme and the shared checks in `StompTransferChecks`). The answered transfer subscribes to `/q` and writes the one
MESSAGE frame's body. Expected values come from curl's manual page for curl 8.22.0 (curl.se/docs/manpage.html) and
ADR-1059. `--fail` and `--fail-with-body` concern HTTP response codes and STOMP has none: ADR-1059 deliberately ends an
`ERROR` frame with exit 8 (`STOMP server sent ERROR: <message>`) with or without them, so those rows pin exit 8, not 22.
IDs are `CurlSurface:Stomp<option>-<n>`, `n` 1 for `stomp` and 2 for `stomps`.

| ID | Level | Requirement | Covered by |
|----|-------|-------------|------------|
| CurlSurface:StompVerbose-1 | MUST | `stomp`: `-v` writes curl 8.22.0's connection line (`* Established connection to localhost (127.0.0.1 port N) from ...`) on standard error, and standard output holds the body alone (manual, "-v"). | StompTransferSurfaceCases.Verbose_Answered_WritesTheConnectionLineOnStandardErrorAndOnlyTheBodyOnStandardOutput |
| CurlSurface:StompOutput-1 | MUST | `stomp`: `-o file` in a temporary directory writes the body to the file and nothing to standard output (manual, "-o"). | StompTransferSurfaceCases.Output_Answered_WritesTheBodyToTheFileAndNothingToStandardOutput |
| CurlSurface:StompRemoteName-1 | MUST | `stomp`: `-O` (under `--output-dir`) writes the body to a file named after the URL path's last segment, `q`, and nothing to standard output (manual, "-O"). | StompTransferSurfaceCases.RemoteName_Answered_WritesTheBodyToTheFileNamedAfterTheUrl |
| CurlSurface:StompWriteOut-1 | MUST | `stomp`: `-w` writes `%{exitcode}` 0, an empty `%{errormsg}`, `%{url}` and `%{url_effective}` as given, `%{scheme}` the URL's scheme, `%{remote_ip}` 127.0.0.1, `%{remote_port}` the port, `%{size_download}` the bytes written and `%{time_total}` 0.000000 on an injected clock that never moves, after the body (manual, "-w"). | StompTransferSurfaceCases.WriteOut_Answered_WritesEveryVariableAfterTheBody |

| CurlSurface:StompFailWithBody-1 | MUST | `stomp`: `--fail-with-body` against an `ERROR` frame ends the same way, exit 8 (ADR-1059; manual, "--fail-with-body", "EXIT CODES" 8). | StompTransferSurfaceCases.FailWithBody_ErrorFrame_EndsWithExit8AndTheMessage |
