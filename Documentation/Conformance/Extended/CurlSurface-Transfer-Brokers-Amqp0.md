# CurlSurface: transfer options for the AMQP 0-9-1 schemes

curl's generic transfer options (`-v`, `-o`, `-O`, `-w`, `--fail`, `--fail-with-body`, `-m`) for `amqp` and `amqps`
(ADR-1091), run through the real curl command line in process against `Amqp0ReferenceBroker` on ports 5672 and 5671
(`amqps` over the harness's TLS route with a self-signed certificate and `-k`), on a fake clock that moves only when
a check advances it (`Curl.Conformance.Extended.UnitTests/CurlSurface/Transfer/Brokers/Amqp0/`: `AmqpTransferSurfaceCases`,
`AmqpsTransferSurfaceCases` and the shared checks in `Amqp0TransferChecks`). The answered transfer is a basic.get of one
message from `/vh/q`. Expected values come from curl's manual page for curl 8.22.0 (curl.se/docs/manpage.html) and the
extension's ADRs. The extension maps no server error to exit 22: ADR-1060 ends a broker's channel.close with exit 8
(67 for 403), and `--fail` and `--fail-with-body` concern HTTP response codes, so the `--fail` rows pin ADR-1060's
exit 8. IDs are `CurlSurface:Amqp0<option>-<n>`, `-1` for `amqp` and `-2` for `amqps`.

| ID | Level | Requirement | Covered by |
|----|-------|-------------|------------|
| CurlSurface:Amqp0Verbose-1 | MUST | `amqp`: `-v` writes the connection line (`* Established connection to localhost (127.0.0.1 port 5672) from ...`) on standard error, and standard output holds the message body alone (manual, "-v"). | AmqpTransferSurfaceCases.Verbose_Answered_WritesConnectionLinesOnStandardErrorAndOnlyTheBodyOnStandardOutput |
| CurlSurface:Amqp0Output-1 | MUST | `amqp`: `-o file` in a temporary directory writes the message body to the file and nothing to standard output (manual, "-o"). | AmqpTransferSurfaceCases.Output_Answered_WritesTheBodyToTheFileAndNothingToStandardOutput |
| CurlSurface:Amqp0RemoteName-1 | MUST | `amqp`: `-O` (under `--output-dir`) writes the message body to a file named after the URL path's last segment, the queue `q`, and nothing to standard output (manual, "-O"). | AmqpTransferSurfaceCases.RemoteName_Answered_WritesTheBodyToTheFileNamedAfterTheQueue |
| CurlSurface:Amqp0WriteOut-1 | MUST | `amqp`: `-w` writes `%{exitcode}` 0, an empty `%{errormsg}`, `%{url}` and `%{url_effective}` as given, `%{scheme}` `amqp`, `%{remote_ip}` 127.0.0.1, `%{remote_port}` 5672, `%{size_download}` the body's bytes and `%{time_total}` 0.000000 on an injected clock that never moves, after the body (manual, "-w"). | AmqpTransferSurfaceCases.WriteOut_Answered_WritesEveryVariableAfterTheBody |
| CurlSurface:Amqp0Fail-1 | MUST | `amqp`: `--fail` against a broker that closes the channel with reply code 404 ends with exit 8, `curl: (8) AMQP server sent channel.close: reply code 404, ...` on standard error and `%{exitcode}`/`%{errormsg}` agreeing, not exit 22: `--fail` concerns HTTP response codes (manual, "--fail", "EXIT CODES" 8; ADR-1060). | AmqpTransferSurfaceCases.Fail_ChannelClosedByTheBroker_EndsWithExit8NotExit22 |
| CurlSurface:Amqp0FailWithBody-1 | MUST | `amqp`: `--fail-with-body` against that broker ends the same way, exit 8 (manual, "--fail-with-body", "EXIT CODES" 8; ADR-1060). | AmqpTransferSurfaceCases.FailWithBody_ChannelClosedByTheBroker_EndsWithExit8NotExit22 |
| CurlSurface:Amqp0MaxTime-1 | MUST | `amqp`: `-m 100` against a broker that never answers ends with exit 28 and `curl: (28) ...` once the injected clock reaches the deadline, with nothing on standard output (manual, "-m", "EXIT CODES" 28). | AmqpTransferSurfaceCases.MaxTime_BrokerNeverAnswers_EndsWithExit28AtTheDeadlineOnTheInjectedClock |

| CurlSurface:Amqp0Output-2 | MUST | `amqps`: `-o file` in a temporary directory writes the message body to the file and nothing to standard output (manual, "-o"). | AmqpsTransferSurfaceCases.Output_Answered_WritesTheBodyToTheFileAndNothingToStandardOutput |
| CurlSurface:Amqp0RemoteName-2 | MUST | `amqps`: `-O` (under `--output-dir`) writes the message body to a file named after the URL path's last segment, the queue `q`, and nothing to standard output (manual, "-O"). | AmqpsTransferSurfaceCases.RemoteName_Answered_WritesTheBodyToTheFileNamedAfterTheQueue |
| CurlSurface:Amqp0WriteOut-2 | MUST | `amqps`: `-w` writes `%{exitcode}` 0, an empty `%{errormsg}`, `%{url}` and `%{url_effective}` as given, `%{scheme}` `amqps`, `%{remote_ip}` 127.0.0.1, `%{remote_port}` 5671, `%{size_download}` the body's bytes and `%{time_total}` 0.000000 on an injected clock that never moves, after the body (manual, "-w"). | AmqpsTransferSurfaceCases.WriteOut_Answered_WritesEveryVariableAfterTheBody |
