# CurlSurface: transfer options for the AMQP 1.0 broker schemes

curl's generic transfer options (`-v`, `-o`, `-O`, `-w`, `--fail`, `--fail-with-body`, `-m`) for `amqp1` and `amqp1s`
(ADR-1062), run through the real curl command line in process against `Amqp1ReferenceContainer`
(`Curl.Conformance.Extended.UnitTests/CurlSurface/Transfer/Brokers/Amqp1/`: `Amqp1TransferSurfaceCases` for `amqp1`
in clear on 5672, `Amqp1sTransferSurfaceCases` for `amqp1s` over TLS on 5671 with `-k`, and the shared checks in
`Amqp1TransferChecks`). Each answered check receives one message from the address `queue`. Expected values come from
curl's manual page for curl 8.22.0 (curl.se/docs/manpage.html) and the extension's ADRs. The extension maps no AMQP
error to exit 22: `--fail` and `--fail-with-body` concern HTTP response codes, so a link the container refuses with
`amqp:not-found` still ends with ADR-1062's exit 78 under either option (ADR-1219). IDs are
`CurlSurface:Amqp1<option>-<n>`, `-1` for `amqp1` and `-2` for `amqp1s`.
