# CurlSurface: -s and -S for every extended scheme

curl's `-s` and `-S` for every scheme an extension serves, run through the real curl command line in process with no
reference server (`Curl.Conformance.Extended.UnitTests/CurlSurface/Transfer/Silent/`, one case file per extension, its
schemes as data rows, and the shared checks in `SilentChecks`). Expected values come from curl's manual page for curl
8.22.0 (curl.se/docs/manpage.html): "-s, --silent": "Silent or quiet mode. Do not show progress meter or error
messages", and "-S, --show-error": "When used with -s, --silent, it makes curl show an error message if it fails". The
failing transfers are the URL-error checks' own (`CurlSurface-Transfer-UrlErrors.md`): a port past 65535, which curl
rejects before any transfer starts, and port 1, which no reference server answers, so the transfer starts and would
show a progress meter; only the options differ, and the error text is the one that matrix measured with
`Record-CurlExchange.ps1`. `demo` stands for a `curl-proto-<scheme>` helper scheme (ADR-1142), with a helper program
on PATH; no case starts a program. `TransferSurfaceSchemeCoverageTests` checks that every scheme an extension's
description registers has a row for each of BL-4496's checks across the `CurlSurface-Transfer*.md` matrices (a
`--fail` row whose requirement also names `--fail-with-body` counts for both, as the process schemes' matrix writes
them). IDs are `CurlSurface:<check>-<scheme>-<n>`.
