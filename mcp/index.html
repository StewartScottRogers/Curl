Set up the Curl MCP server

Curl.Mcp is an MCP server over stdio. It gives an agent a curl tool and the --ai-help reference as resources. Download its packages from the download page (kind mcp-server), put every Curl.Mcp nupkg in one folder, and launch it with dnx Curl.Mcp --yes --prerelease --add-source <folder>. The configurations below assume that folder is /path/to/curl-packages; change it.

CURL_MCP_ROOT is the only directory the tool may read or write; set it to the project folder. With it unset every file path is refused. Details: Curl.Mcp README.

Checked against: the VS Code shape is the one in Curl.Mcp/README.md. The Claude Desktop, Claude Code and Copilot shapes are the clients' documented shapes as of 2026-10-22 (mcpServers in claude_desktop_config.json; claude mcp add; servers in .vscode/mcp.json for Copilot in VS Code). They were written from knowledge of that documentation and not fetched while building this page, so if a client rejects one, its own documentation wins.

Claude Desktop

Edit claude_desktop_config.json (Settings, Developer, Edit Config) and restart Claude Desktop:

{
  "mcpServers": {
    "curl": {
      "command": "dnx",
      "args": ["Curl.Mcp", "--yes", "--add-source", "/path/to/curl-packages"],
      "env": { "CURL_MCP_ROOT": "/path/to/project" }
    }
  }
}

Claude Code

claude mcp add curl --env CURL_MCP_ROOT=/path/to/project -- dnx Curl.Mcp --yes --prerelease --add-source /path/to/curl-packages

VS Code

Add to .vscode/mcp.json in the workspace:

{
  "servers": {
    "curl": {
      "type": "stdio",
      "command": "dnx",
      "args": ["Curl.Mcp", "--yes", "--add-source", "/path/to/curl-packages"],
      "env": { "CURL_MCP_ROOT": "${workspaceFolder}" }
    }
  }
}

Copilot

GitHub Copilot in VS Code reads the same .vscode/mcp.json as above: use that block, then choose Agent mode and enable the curl tools. For Copilot in Visual Studio, put the same block in .mcp.json in the solution folder.

See also: llms.txt, --ai-help reference.
