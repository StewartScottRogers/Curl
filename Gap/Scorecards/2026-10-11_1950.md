## Closed

- GF-0002 In process, Curl opens a new connection for every request, so connection-reuse cases see [DISCONNECT], local port -1 and the wrong verdict for the second response (Critical)
- GF-0011 --url @file and --url @- are taken as a literal URL instead of a list of URLs to read (High)
- GF-0018 -F multipart bodies differ: custom Content-Type, several files in one -F, quoted file names with , ; " (High)
- GF-0020 -K: a missing file's message omits the path, and a Unicode quote in a config file is read differently (High)
- GF-0051 FTP sends QUIT and closes after every URL; curl keeps the control connection for the next URL and sends QUIT only at exit (High)
- GF-0057 IMAP logs out after every URL instead of reusing the connection, and every connection's tags start with A where curl uses one letter per connection (High)
- GF-0058 -F to an smtp:// or imap:// URL is not sent as a MIME message: SMTP sends VRFY and IMAP sends LIST (High)
- GF-0061 POP3 with CRAM-MD5 as the only offered mechanism sends no AUTH at all (High)
