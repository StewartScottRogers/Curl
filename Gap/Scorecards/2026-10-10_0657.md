## New gaps

- GF-0045 Through -p/-x the proxy server receives nothing in process: every <verify><proxy> case records no CONNECT (High)
- GF-0046 SOCKS4/5 proxies and --interface are never used in process: the request goes straight to the server and their exit codes (97, 7, 45) never arise (High)
- GF-0047 A case's <setenv> (NO_PROXY, HOME, XDG_CONFIG_HOME, CURL_HOME) never reaches Curl in process, so curlrc, .ipfs/gateway and NO_PROXY lookups differ (High)
- GF-0048 FTP active mode (-P) hangs in process: the FTP stand-in's PORT/EPRT cannot reach Curl's real TCP listener (High)
- GF-0049 TFTP requests drop every leading slash of the URL path; curl drops only the first, so tftp://host//N asks for /N (High)
- GF-0050 An over-long TFTP file name fails with exit 7 when the channel cannot open, where curl refuses it first with exit 71 (High)
- GF-0051 FTP sends QUIT and closes after every URL; curl keeps the control connection for the next URL and sends QUIT only at exit (High)
- GF-0052 --ignore-content-length does not stop FTP from sending SIZE before RETR (High)
- GF-0053 An FTP reply holding a NUL byte or control characters (in PWD's path) is accepted; curl ends with exit 8 (High)
- GF-0054 When the EPSV data port cannot be connected, FTP does not fall back to PASV (High)
- GF-0055 A reply pipelined behind STARTTLS/AUTH TLS is not refused with exit 8, and a pre-authenticated FTP server skips AUTH under --ssl-reqd (High)
- GF-0056 --netrc-optional lets the netrc password override the URL's, and a .netrc holding a NUL byte stops the transfer (High)
- GF-0057 IMAP logs out after every URL instead of reusing the connection, and every connection's tags start with A where curl uses one letter per connection (High)
- GF-0058 -F to an smtp:// or imap:// URL is not sent as a MIME message: SMTP sends VRFY and IMAP sends LIST (High)
- GF-0059 ;AUTH=EXTERNAL with no user name skips SASL; curl sends AUTH EXTERNAL with an empty (=) response (High)
- GF-0060 A SASL exchange given a bad challenge (CRAM-MD5 rubbish, a broken NTLM type-2) is not cancelled with * and retried with the next mechanism (High)
- GF-0061 POP3 with CRAM-MD5 as the only offered mechanism sends no AUTH at all (High)
- GF-0062 SMTP AUTH PLAIN over two URLs with -: sends an empty authorization identity; upstream expects user, user, password (High)
- GF-0063 --mail-from '<addr> RET=HDRS' gains a trailing '>' after the parameters; curl sends an address that starts with '<' as given (High)
- GF-0064 --crlf does not convert an SMTP upload's LF line ends to CR LF (High)
- GF-0065 VRFY and EXPN replies are written to the output with LF where curl writes the server's CR LF (High)
- GF-0066 A backslash in a URL path is sent as '/', where curl sends it as written (High)
